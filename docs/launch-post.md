## 标题（三选一）

1. 我给 DSH 写了个插件：把「深度求索中」换成 287 条双语短语
2. DSH 的状态行终于不那么单调了（附词池可自己改的方法）
3. 从 Claude Code 的 spinner 词抄了个思路，做了个能自己改词池的 DSH 插件

第一条最稳：说清做了什么，没有形容词。第三条有来历，适合技术社区。

## 正文

> 给 DeepSeek Harness 写了个小插件，改的是思考状态行。
>
> 默认状态行永远是一句「深度求索中」。我把 Claude Code 的 spinner 词、鲸鱼系短语和中国本土文化词凑成 287 条，做成每回合换一条的双语词池，点一下状态行切中英文。
>
> 几个我自己在意的地方：
>
> - **一回合一个词**，不是每隔几秒换一条。Claude Code 也是这样：一轮请求里只抽一次，长任务不换词。换太勤会抢注意力。
> - **词池能自己改**。双击状态行（或 Alt+E）打开编辑器，一行一条「英文 | 中文」，存 localStorage，下个回合生效。内置池只是起点。
> - **29 条典故词带英文注脚**，比如「凿壁偷光」→ boring a hole in the wall to steal a neighbor's lamplight，只在悬停时显示，不撑状态行。
> - **只管文案和交互**。图标、动效、尺寸、颜色一律不动，小鲸鱼还是 DSH 自己那只。
>
> 装：
>
> ```bash
> dsh plugin --profile desktop add dsh-spinner-words
> ```
>
> 装完完全退出 DSH 进程再启动。
>
> 仓库：https://github.com/uuicdown/dsh-spinner-words
> npm：https://www.npmjs.com/package/dsh-spinner-words
> MIT，词表来源都写在 README 里。
>
> 注意：和 `dsh-deep-verbs` 抢同一个状态行节点，两个只能留一个。
>
> 词池喜欢什么风格、哪条翻得别扭，欢迎直接告诉我——改词比改代码简单。

## GIF 录制方案

目标 5 秒内说清两件事：每回合换词、点击切中英。

- 工具：ScreenToGif（Windows 免费）或 OBS 录屏后转 GIF
- 尺寸：只裁状态行区域，640×200 左右足够，太大在手机上看不清
- 帧率 20fps，控制在 **2MB 以内**（GitHub 和论坛附件都友好）
- 镜头顺序：发一条消息 → 状态行出现「凿壁偷光中…」→ 点一下变英文 → 再发一条消息 → 换成另一条短语
- 录完存 `docs/demo.gif`，README 里放在截图之后

录好之后放进 README：

```md
<img src="docs/demo.gif" width="480" alt="演示：状态行每回合换一条短语，点击切换中英文">
```

## 别做的

- 刷 npm 下载量：市场权重看增长与更新，且有反作弊，被标注得不偿失
- 无意义地连发版本号：`⚡更新勤` 是 30 天内 ≥10 次**真实**发版，空 bump 会被用户看出
- 去 `dsh-deep-verbs` 的 issue 区推销：同行挖墙脚，观感很差。正确做法是在自己 README 写清二选一
